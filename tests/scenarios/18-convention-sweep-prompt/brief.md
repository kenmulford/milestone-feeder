# Brief: amount field shows "0.00" the user must delete

On four forms (add expense, edit expense, budget limit, transfer), the amount field opens
showing "0.00" as real text. The user has to delete it before typing an amount, and a stray
zero is easy to leave behind. Fix the amount field on those forms.

In scope:
- The four forms above.

Out of scope:
- Any other form.
- Currency formatting rules.
